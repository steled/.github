# Security Policy

Thank you for helping to keep my projects safe.

## Reporting a vulnerability

**Please do not report security issues in public issues or pull requests.**

Use GitHub's private vulnerability reporting instead:

1. Open the **Security** tab of the affected repository.
2. Click **Report a vulnerability** and describe the problem (affected version, steps to reproduce, impact).

If the repository does not offer this option, open a public issue that only says you would like to report a security problem (without any details). I will get in touch and we can continue privately.

## What to expect

These are personal projects maintained in my spare time. I will try to acknowledge a report within a few days and to publish a fix and an advisory as soon as reasonably possible. Reports are handled on a best-effort basis.

## Supported versions

Only the latest release (or the default branch for projects without releases) receives security fixes.
